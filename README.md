# Sum up 19 November's world news in one image

A deterministic, hand-drawn broadsheet for Thursday 19 November 2026. Its seven stories pair concise serif headlines and full reported wording with small vector-style illustrations, led by a Vice City launch panel and a world-court feature. The Python standard-library renderer writes a 1024×1024 RGB PNG; `main.ts` validates it and copies it to the competition output directory.
